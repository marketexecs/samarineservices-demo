# SA Marine Services redesign demo

Independent concept prepared by Market Execs, based on the live homepage inspected October 18, 2026. The original production website is untouched.

## Review before publishing

Open index.html in your browser after downloading and extracting the entire folder. No installation or subscription is needed. Images are included locally. Resize the window or review on a phone after enabling the separate GitHub Pages preview.

Check the navigation, service descriptions, all project photos, and booking/call preview dialogs. Contact buttons deliberately do not send requests or place calls. External links to the existing website, parts shop and YouTube are labeled.

## Free GitHub preview

This repository is only the demo. In its Settings > Pages, select Deploy from a branch, branch demo/redesign, folder / (root), then Save. This publishes a public demo at https://marketexecs.github.io/samarineservices-demo/ once GitHub completes deployment. Do not enter a custom domain. Do not change DNS. There is no CNAME file and no production deployment workflow.

Publishing the demo does not publish to samarineservices.com. Changing the actual business website requires a separate review, business-owner approval, confirmed hosting access and a rollout plan.

## Source and behavior

Original source: https://samarineservices.com/

Preserved: existing logo; original hero, lift and project photographs; navy, white and teal from the current site; factual repair, maintenance, installation, controls and waterfront service content; Palm Beach, Broward and Miami-Dade service areas; existing phone number; original video guide destination.

Asset URLs, sizes and SHA-256 hashes are in asset-sources.json. Images were downloaded from the existing site's image CDN. Their rights remain with their respective owners. Confirm business-owner permission before using the concept as an official replacement.

Changed: page hierarchy, typography, spacing, navigation, gallery presentation, mobile layout, keyboard focus styles and contact flow. Duplicate sections, tracking scripts, animated effects and third-party review widgets were omitted. No new performance claims, testimonials, prices or credentials were added. Existing same-day service wording is qualified by availability. No analytics, forms, payments or data collection were added. The page includes noindex,nofollow, which requests search engines not index it but is not an access restriction.
